
# node-red-contrib-nadhem-iot

## Overview

This is a custom Node-RED node developed for IoT applications.

The node receives an input message and replaces its payload with the constant string "Nadhem Zini".

## How to use

1. Install the node-red-contrib-nadhem-iot package.
2. Open Node-RED.
3. Add the nadhem-iot node to your flow.
4. Connect an Inject node to nadhem-iot.
5. Connect a Debug node to visualize the output.
6. Deploy and execute the flow.

The output will always be:

"Nadhem Zini"

## Requirements

- Node.js
- Node-RED
- npm
